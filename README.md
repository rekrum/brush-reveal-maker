# Brush Reveal Maker v1.0

透過PNG/WebPのロゴを、指定した筆跡に沿って筆書き風に露出するブラウザツールです。

## 使い方
1. `index.html` を Chrome で開く
2. 透過PNG/WebPを読み込む
3. 文字の中心を1画ずつドラッグする
4. 必要なら画を選択して描き直し・制御点編集を行う
5. プレビューして WebM / MP4 / GIF で書き出す

## v1.0 の変更
- 筆の太さを基本の露出幅として統一
- 従来の「露出幅」を廃止し、詳細設定の「露出余白 +0〜40px」に変更
- 初期値は +0px。文字の端が残る場合だけ追加してください
- v0.3.1 のJSONは読み込み時に旧露出幅から露出余白へ変換します

## 推奨環境
Windows / macOS の最新 Google Chrome。
GIF出力時はエンコーダーをCDNから読み込むためインターネット接続が必要です。
